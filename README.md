# 🧮 Mathdle (เกมทายสมการคณิตศาสตร์)

ยินดีต้อนรับสู่เกม Mathdle! เกมทายสมการที่สนุกและท้าทายสมอง คุณต้องทายสมการให้ถูกภายใน 6 ครั้ง โดยตัวเลขและสัญลักษณ์จะเปลี่ยนสีตามความถูกต้อง

### 🎮 วิธีการเล่น (ภาษาไทย)
1. **เลือกความยาก:** เลือกจำนวนหลักของสมการที่ต้องการเล่น (5, 6, 7 หรือ 8 หลัก) จากเมนูด้านบน
2. **พิมพ์คำทาย:** กดที่ปุ่มตัวเลขและเครื่องหมาย (+, -, *, /) เพื่อสร้างสมการ
   * *ตัวอย่าง:* หากเลือก 5 หลัก คุณอาจทายว่า `4+1=5`
3. **ตรวจสอบความถูกต้อง:** หลังจากกด ENTER สีของช่องจะเปลี่ยนไปดังนี้:
   * 🟩 **สีเขียว:** ตัวเลข/สัญลักษณ์นี้ **ถูกต้อง** และ **วางถูกตำแหน่ง**
   * 🟨 **สีเหลือง:** ตัวเลข/สัญลักษณ์นี้ **มีอยู่ในสมการ** แต่ **วางผิดตำแหน่ง**
   * ⬛ **สีเทา:** ตัวเลข/สัญลักษณ์นี้ **ไม่มีอยู่ในสมการ**
4. **เงื่อนไข:** สมการที่ทายต้องเป็นจริงเสมอ (เช่น ถ้าทาย `1+1=3` เกมจะแจ้งว่า Math Invalid!)
5. **ชัยชนะ:** ทายสมการให้ถูกต้องครบทุกช่องภายใน 6 โอกาส!
